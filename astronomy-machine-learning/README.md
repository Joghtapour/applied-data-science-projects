# Galaxy Redshift and Pulsar Detection

An in-progress machine learning notebook covering two astronomy tasks. The regression exercise aims to estimate galaxy redshift from five Sloan Digital Sky Survey brightness bands. The classification exercise aims to distinguish pulsar candidates from other radio signals using eight signal statistics.

[Open the notebook](astronomy-machine-learning.ipynb)

The regression section loads and explores the SDSS data, filters to galaxies, and creates a train/test split. The pulsar section documents the features and target. Model training and evaluation are pending.
