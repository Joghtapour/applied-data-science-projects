# Applied Data Science Projects

Jupyter notebooks covering exploratory data analysis, statistical inference, and applied machine learning.

## [Global Suicide Mortality Rates, 2000–2021](global-suicide-mortality/)

An exploratory analysis of global suicide mortality rates and socioeconomic indicators using a dataset compiled from WHO and World Bank data. The notebook covers data cleaning, exploratory plots, a chi-square test of independence, and a Welch t-test.

Open the notebook in Jupyter and run the cells in order. The notebook uses KaggleHub to retrieve the source dataset.

## [Galaxy Redshift and Pulsar Detection](astronomy-machine-learning/)

An in-progress machine learning notebook covering two astronomy tasks. The regression exercise aims to estimate galaxy redshift from five Sloan Digital Sky Survey brightness bands. The classification exercise aims to distinguish pulsar candidates from other radio signals using eight signal statistics.

The regression section loads and explores the SDSS data, filters to galaxies, and creates a train/test split. The pulsar section documents the features and target. Model training and evaluation are pending.
