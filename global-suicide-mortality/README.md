# Global Suicide Mortality Rates, 2000–2021

An exploratory analysis of global suicide mortality rates and socioeconomic indicators using a dataset compiled from WHO and World Bank data. The notebook covers data cleaning, exploratory plots, a chi-square test of independence, and a Welch t-test.

[Open the notebook](global-suicide-mortality.ipynb)

Open the notebook in Jupyter and run the cells in order. The notebook uses KaggleHub to retrieve the source dataset.
